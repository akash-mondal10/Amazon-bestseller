# Data

The raw file is not committed (37 MB). To rebuild everything:

1. Download **Amazon Kindle Books Dataset 2023 (130K Books)** by asaniczka from Kaggle:
   https://www.kaggle.com/datasets/asaniczka/amazon-kindle-books-dataset-2023-130k-books
2. Put `kindle_data-v2.csv` in `data/raw/`.
3. From the repo root run `python analysis/run.py`.

Check the dataset's licence on its Kaggle page before redistributing it.
